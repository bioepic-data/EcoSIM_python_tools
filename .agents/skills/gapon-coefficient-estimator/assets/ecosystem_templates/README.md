# Bundled Ecosystem Templates

The case directories and `index.csv` were copied verbatim on 2026-08-05 from:

`/Users/jinyuntang/work/github/ECOSYS_workspace/ecosys16022024/ecosys benchmark runs 2024/soil_gapon_by_case/`

The source library contains 19 ecosystem case CSVs and 24 distinct soil
profiles. `template_catalog.csv` is the skill-specific matching index added to
the copied library; it does not replace or modify the source files.

These profiles provide depth-explicit EcoSIM starting values. They are
template-based, not measurements for a target site, and are subject to
calibration or tuning when needed.
